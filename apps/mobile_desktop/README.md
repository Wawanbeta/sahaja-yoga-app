# Mobile/Desktop App

Geplanter Stack:

- Flutter
- Dart
- SQLite/Drift fuer lokale Daten
- Riverpod oder BLoC fuer State Management
- GoRouter fuer Navigation

## Zielplattformen

- iOS/iPadOS
- Android
- Windows
- optional macOS
- optional Web

## Geplante Feature-Struktur

```text
lib/
|-- app/
|-- core/
|-- features/
|   |-- inspiration/
|   |-- meditation/
|   |-- mantras/
|   |-- media_library/
|   |-- journal/
|   |-- offline/
|   `-- settings/
`-- shared/
```
