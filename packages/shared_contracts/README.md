# Shared Contracts

Dieser Bereich enthaelt gemeinsame Datenvertraege zwischen App und Backend.

Geplant:

- OpenAPI-Spezifikation
- JSON Schemas
- generierte TypeScript-Typen
- spaeter generierte Dart-Modelle oder Mapping-Regeln

Grundsatz:

Die App soll gegen stabile interne Vertraege arbeiten, nicht gegen rohe externe API-Antworten.
