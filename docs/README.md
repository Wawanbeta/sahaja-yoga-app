# Dokumentationsindex

Dieser Ordner trennt Produkt, Architektur, Design und Delivery. Dadurch koennen Entscheidungen nachvollzogen werden, bevor sie in Code gegossen werden.

## Bereiche

- `product/`: Zielbild, Produktstruktur, Backlog, Roadmap, Skill-Gaps
- `architecture/`: Systemarchitektur, API, Daten, Datenschutz, ADRs
- `design/`: UX-Flows, Designsystem, Accessibility-Grundlagen
- `delivery/`: Entwicklungsprozess, Definition of Done, Test- und Release-Qualitaet

## Arbeitsregel

Neue groessere Entscheidungen werden als ADR in `docs/architecture/adr/` dokumentiert. Produktentscheidungen, die den MVP-Scope veraendern, werden im Backlog und in der Roadmap nachgezogen.
