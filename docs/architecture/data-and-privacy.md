# Daten und Datenschutz

Status: Startkonzept

## Datenklassen

### Oeffentliche Inhalte

Beispiele:

- Inspirationen
- Talks
- Mantren
- Meditationstexte
- Kursinhalte

Anforderungen:

- Quelle speichern
- Freigabestatus speichern
- Sprache speichern
- Lizenz-/Rechtestatus speichern, falls relevant

### Private Nutzerdaten

Beispiele:

- Tagebuch
- Favoriten
- Verlauf
- Spracheinstellung
- optionales Profil

Anforderungen:

- so viel wie moeglich lokal speichern
- Cloud-Sync optional machen
- Export und Loeschung vorsehen
- keine Tagebuchinhalte fuer Analytics verwenden

### Community-Daten

Beispiele:

- Threads
- Kommentare
- Meldungen
- Moderationsentscheidungen

Anforderungen:

- erst nach MVP
- Moderation vor Launch
- Melde- und Sperrfunktionen
- App-Store-Regeln fuer User Generated Content beachten

## Lokale App-Daten

Empfehlung:

- SQLite fuer Inhalte und Status
- Secure Storage fuer Tokens
- lokale Dateien fuer heruntergeladene Medien

## Datenschutzprinzipien

- Konto optional
- Tagebuch privat
- Analytics optional und einwilligungsbasiert
- Datenminimierung
- klare Einstellungen fuer Export und Loeschung
- keine sensiblen Rueckschluesse ohne Zustimmung

## Offene rechtliche Punkte

- DSGVO-Rechtsgrundlage
- Datenschutzerklaerung
- Altersfreigabe
- Medienrechte
- Offline-Speicherung externer Inhalte
- App-Store-Datenschutzangaben
