# Designsystem

Status: Startstruktur

## Designprinzipien

- ruhig und klar
- wenige Entscheidungen pro Screen
- Inhalte zuerst, Dekoration danach
- Accessibility als Standard
- keine Ueberladung durch spirituelle oder technische Begriffe
- konsistent ueber Mobile und Desktop

## Design-Tokens

Geplante Token-Gruppen:

- Farbe
- Typografie
- Abstaende
- Radius
- Schatten
- Motion
- Breakpoints
- Icongroessen

## Accessibility-Basics

- ausreichende Kontraste
- dynamische Schriftgroessen unterstuetzen
- Touch Targets gross genug halten
- Screenreader-Labels fuer Icons und Player
- Tastaturbedienung fuer Desktop
- keine wichtigen Informationen nur ueber Farbe transportieren
