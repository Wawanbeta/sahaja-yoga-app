# UX-Flows

Status: Startstruktur

## Kernflow 1: Inspiration -> Meditation -> Tagebuch

1. App startet auf Tagesinspiration.
2. Nutzer waehlt passende Meditation.
3. Meditation startet mit Timer oder Audio.
4. Nach Abschluss erscheint ruhiger Abschlusszustand.
5. Nutzer kann Tagebuchnotiz schreiben.

Erfolg:

- Nutzer kommt ohne Konto in die erste Praxis.
- Tagebuch bleibt lokal und privat.

## Kernflow 2: Inspiration -> Mediathek

1. Tagesimpuls zeigt Quelle oder Thema.
2. Nutzer oeffnet verknuepften Talk.
3. App zeigt Titel, Datum, Ort, Sprache und Inhalt.
4. Nutzer kann Favorit speichern.

Erfolg:

- Inspiration fuehrt in verifizierbare Vertiefung.

## Kernflow 3: Mediathek-Suche

1. Nutzer oeffnet Mediathek.
2. Nutzer sucht nach Begriff.
3. Nutzer filtert optional nach Sprache, Jahr, Land oder Kategorie.
4. Nutzer oeffnet Talk-Detail.

Erfolg:

- Suche bleibt auch bei API-Fehlern verstaendlich.

## Kernflow 4: Offline-Praxis

1. App erkennt fehlende Verbindung.
2. Nutzer sieht verfuegbare Offline-Inhalte.
3. Nutzer startet Meditation oder oeffnet Mantra.
4. Tagebuchnotiz wird lokal gespeichert.

Erfolg:

- Offline fuehlt sich nicht wie ein Fehlerzustand an.
