# Release-Roadmap

Status: Arbeitsversion

## R0: Vorbereitung

Ziel:

- Produktumfang, Rechte, Quellen und technische Richtung klaeren.

Ergebnisse:

- Rechte- und Quellenliste
- MVP-Backlog
- Architekturentscheidung
- Projektstruktur

## R1: Technischer Proof of Concept

Ziel:

- Nachweisen, dass Flutter-App, eigene API und Learn-Sahaja-Yoga-Integration zusammenspielen.

Umfang:

- Flutter-App-Shell
- API-Prototyp
- Talk-Suche ueber eigene API
- lokale Speicherung eines Favoriten

## R2: Interner MVP

Ziel:

- Kernschleife intern nutzbar machen.

Umfang:

- Tagesinspiration
- Meditationstimer
- Mantren-Liste
- Mediathek-Suche
- Tagebuch lokal
- Offline-Seed

## R3: Beta

Ziel:

- Test mit kleiner Gruppe auf echten Geraeten.

Umfang:

- TestFlight
- Google Play Internal Testing
- Windows-Testbuild
- Content-Review
- Datenschutztexte

## R4: Public Release

Ziel:

- kontrollierte Veroeffentlichung.

Umfang:

- App Store
- Google Play
- Windows-Distribution
- Monitoring
- Support-Prozess

## R5: Erweiterungen

Moegliche Themen:

- Kursbereich
- Cloud-Sync
- Community
- Push Notifications
- KI-gestuetzte Empfehlungen
- macOS/Web
